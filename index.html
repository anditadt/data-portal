Deskripsi & Cakupan Data

Kumpulan data telemetri komprehensif dari jutaan iklan kendaraan aktif dan transaksi terkonfirmasi di platform OLX Autos seluruh Indonesia.

  • Diperbarui setiap 5-15 menit secara langsung dari stream transaksi pasar sekunder.
  • Meliputi parameter model, tahun pembuatan, transmisi, odometer (jarak tempuh), dan indeks depresiasi.
  • Gunakan parameter timestamp atau date_time untuk mengambil snapshot pasar pada rentang waktu spesifik.

Parameter Kueri (Query Parameters)

Parameter Tipe Keterangan
date_time string (ISO 8601) YYYY-MM-DD[T]HH:mm:ss (WIB / UTC+7)
region_id string (opsional) Kode kota/provinsi BPS (contoh: 3171 untuk Jaksel)
limit integer Jumlah data per halaman respons (default: 50, maks: 500)
